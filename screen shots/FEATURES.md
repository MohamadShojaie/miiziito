# Cafe Management Panel — Screenshot Features Guide

This document explains the features shown in each screenshot from the Lumiere cafe management panel (RTL, Persian UI). Screenshots are listed in capture order.

---

## 1. `Screenshot 1405-06-11 at 18.33.09.png`

**Screen:** Orders (سفارش‌ها)

**Features shown:**
- Live connection status (“Online – Live connection”)
- Quick action: **+ New Order**
- Orders list with search (table, item)
- Status filters: All / New / Preparing / Ready
- Order card for a table (time, table number, status badge)
- Line items with quantities and prices, plus order total
- Primary workflow action: **Start Preparing**
- Extra actions via the three-dot menu

---

## 2. `Screenshot 1405-06-11 at 18.33.30.png`

**Screen:** Start Preparation modal (شروع آماده‌سازی)

**Features shown:**
- Confirm sending kitchen/bar tickets for a table
- Split by section: **Kitchen** and **Bar** (checkbox per section)
- Preview ticket card (brand, table, items, quantities)
- Warning when kitchen/bar printer is not registered in Hardware
- Continue without printing, or cancel
- Confirm **Start Preparing**

---

## 3. `Screenshot 1405-06-11 at 18.33.40.png`

**Screen:** Submit Invoice modal (ثبت فاکتور)

**Features shown:**
- Invoice tied to table and time
- Customer lookup by name or mobile; dedicated mobile field
- Payment modes: Single method / Cash + Card / Split between people
- Cash or Card selection
- Option to register invoice as unpaid (debtor)
- Discount code entry and apply
- Manual discount type and amount
- Tax type and tax percentage controls

---

## 4. `Screenshot 1405-06-11 at 18.33.56.png`

**Screen:** Tables (میزها)

**Features shown:**
- Hall and table overview (counts in subtitle)
- Status legend: Empty / Full / Reserved / Inactive
- Add a new hall by name
- Per-hall tools: Edit, Delete, add table by number
- Table tiles with number and status
- Occupied tables highlighted (e.g. red border)

---

## 5. `Screenshot 1405-06-11 at 18.34.06.png`

**Screen:** Single table modal (e.g. Table 14)

**Features shown:**
- Current table status
- Change status: Full / Empty / Inactive / Reserved
- Edit table number / Delete table
- Per-table QR code for customer menu (`?table=…`)
- Download QR as PNG or print
- Message when no order is registered for that table

---

## 6. `Screenshot 1405-06-11 at 18.34.20.png`

**Screen:** Invoices (فاکتورها)

**Features shown:**
- Summary: total invoices, unpaid count, total sales
- Export to **Excel** and **PDF**
- Search by invoice number, table, customer, mobile
- Date filters: Today / Yesterday / This week / This month / All / Custom range
- Filters by status and payment method
- Invoice table: number, table, time, customer, amount, payment, status
- Row actions: Details, Edit, Print, Thermal print

---

## 7. `Screenshot 1405-06-11 at 18.34.31.png`

**Screen:** Invoices — custom date range

**Features shown:**
- Same invoices panel as above
- Custom Persian calendar date range (بازه دلخواه)
- Filtering invoices within a selected from–to period

## 8. `Screenshot 1405-06-11 at 18.34.38.png`

**Screen:** Sales Statistics (آمار فروش)

**Features shown:**
- Today / week / month sales and average invoice
- Debtors total, total payments, discounts, peak hour
- Quick entry to view debtors list
- Donut chart: payment methods (Cash vs Card)
- Bar chart: hourly busyness / paid invoices by hour

## 9. `Screenshot 1405-06-11 at 18.34.48.png`

**Screen:** Debtors modal (بدهکارها)

**Features shown:**
- Total outstanding debt amount
- Search by name, mobile, or invoice number
- List of debtors with amount owed and unpaid invoice count
- Click a person to open their unpaid invoices

## 10. `Screenshot 1405-06-11 at 18.35.13.png`

**Screen:** Unpaid invoice detail (e.g. Invoice #1019)

**Features shown:**
- Invoice header: number, table, time
- Payment status badges (e.g. unpaid / no payment)
- Linked customer name
- Itemized list with quantities and prices
- Amount summary: subtotal, tax, payable total
- Mark as paid (**پرداخت شد**) or close

## 11. `Screenshot 1405-06-11 at 18.35.22.png`

**Screen:** Customer Club (باشگاه مشتریان)

**Features shown:**
- Totals: customers and registered sales
- 30-day / monthly CRM metrics (active, returning, VIP, follow-up, etc.)
- Add new customer; group messaging
- Search and filter chips (All, Active, VIP, Gold+, Birthday, Follow-up, Inactive, …)
- Customer list with phone and tags
- Detail pane: edit/delete, KPIs (avg invoice, visits, last visit, …)
- Loyalty tier: Ordinary / Silver / Gold / VIP

---

## 12. `Screenshot 1405-06-11 at 18.35.33.png`

**Screen:** Send SMS modal (ارسال پیامک)

**Features shown:**
- Recipient name and mobile
- Quick templates: Follow-up / Birthday / Welcome / Return / Free text
- Editable SMS body (name placeholders filled in)
- Opens device SMS app on send (not a server gateway)
- Copy text, cancel, or send to customer

## 13. `Screenshot 1405-06-11 at 18.35.46.png`

**Screen:** Edit Coupon modal (ویرایش کوپن)

**Features shown:**
- Coupon code (English/numeric, no spaces)
- Optional title
- Discount amount and type (e.g. fixed Toman amount)
- Optional expiry date
- Usage limit toggle
- Active/inactive toggle
- Delete, cancel, or save

## 14. `Screenshot 1405-06-11 at 18.35.59.png`

**Screen:** Settings (تنظیمات)

**Features shown:**
- Save changes / reset to defaults
- Quick data summary: orders, invoices, tables, customers
- Recent customers list with invoice counts
- Live **Menu Preview** (colors, header, categories, sample items)
- Cafe/restaurant information section
- Logo and background configuration for the customer-facing menu
